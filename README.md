# 臺灣地震預警系統的演進與發展

這是由簡報 PDF 轉製的 GitHub Pages 互動式網頁，保留原始 50 頁簡報圖片與文字摘要，並加入導覽、搜尋、投影片模式、鍵盤操作、燈箱放大與重點章節互動卡片。

## 本機測試

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
npm run preview
```

## 部署到 GitHub Pages

1. 將本專案內容推送到 `https://github.com/oceanicdayi/cwa_eew_2026_gemini`
2. 到 GitHub repo 的 Settings → Pages
3. Source 選擇 GitHub Actions
4. 推送到 main/master 後會自動部署
